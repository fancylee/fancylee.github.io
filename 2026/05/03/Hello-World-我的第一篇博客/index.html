欢迎来到我的博客！

这是我的第一篇博客文章，标志着我的个人博客正式搭建完成。

博客技术栈

这个博客使用了以下技术搭建：

  • Hexo：快速、简洁且高效的静态博客框架
  • GitHub Pages：免费的静态网站托管服务
  • Markdown：简洁优雅的写作格式

为什么写博客？

写博客有很多好处：

  1. 知识沉淀：将学习和工作中的经验记录下来，方便日后回顾
  2. 分享交流：与同行分享技术心得，共同进步
  3. 锻炼表达：通过写作提升自己的逻辑思维和表达能力
  4. 个人品牌：建立个人技术影响力

接下来写什么？

我计划在这个博客上分享以下内容：

  • Java 后端/移动端/前端/AI开发相关的技术文章
  • 系统架构设计心得
  • 日常学习和工作中的踩坑记录
  • 读书笔记和个人思考

结语

千里之行，始于足下。希望这个博客能够持续更新，成为我技术成长道路上的见证；致力成为一个用AI+技术去解决问题的人。

如果你有任何问题或建议，欢迎通过 GitHub 与我交流！
